# Group7 TicTacToang

## Quick start
1. Clone
   git clone https://github.com/RMIT-Full-Stack-Development-2026A/Group7.git
   cd Group7

2. Install all
   npm run install:all

3. Copy env files
   cp backend/.env.example backend/.env
   cp frontend/.env.example frontend/.env

4. Seed DB
   cd backend
   npm run seed

5. Start dev
   cd repo-root
   npm run dev

Frontend: http://localhost:3000
Backend health: http://localhost:4000/api/health
